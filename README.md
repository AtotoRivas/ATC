# APP ATC

Aplicación web personal de entrenamiento para la Fase 1 (inglés, psicotécnicos y teoría).

- Funciona sin conexión una vez instalada (service worker).
- No tiene servidor ni cuentas: el banco privado y el progreso se guardan solo en el dispositivo (IndexedDB) y se mueven entre dispositivos con copias de seguridad exportadas a mano.
- Este repositorio solo contiene la aplicación y preguntas de ejemplo generadas. Ningún banco privado se publica aquí.

Fuentes: B612 y B612 Mono (SIL Open Font License 1.1, ver `OFL.txt`; van incrustadas en `index.html`).
